PROJECT 1 - RESEARCH & FACT-CHECKER (Arabic + English)
======================================================
Build first. Self-contained: it has its own copy of the core code (agentcore/); see README.md.
Time: 3-4 weeks part-time.


WHAT IT DOES
------------
Give it a claim or a short article, in Arabic or English.
It finds evidence, decides TRUE / FALSE / NOT ENOUGH INFO for each claim, and writes a short
report with citations.

Example:  "The Burj Khalifa was completed in 2015."
Answer:   FALSE - completed in 2010 (source: Wikipedia, "Burj Khalifa", paragraph 1)


FLOW
----
  claim / article (AR or EN)
        |
        v
  [Planner]  splits the text into separate checkable claims, detects the language
        |
        v  (runs in parallel)
  [Wikipedia searcher]   [Paper searcher (arXiv/OpenAlex)]   [Knowledge base searcher (RAG)]
        |                         |                                   |
        +-------------------------+-----------------------------------+
        v
  [Reader]   pulls the exact sentences that support or contradict each claim
        |
        v
  [Judge]    TRUE / FALSE / NOT ENOUGH INFO + confidence (0-1)
        |      if confidence < 0.6 -> back to searchers for one more round (max 2)
        v
  [Writer]   short report with citations, in the user's language
        |
        v
  [Me: approve / edit / reject]  before the verdict is "published"


AGENTS
------
Planner      - splits claims, detects Arabic/English
Searchers    - Wikipedia (EN + AR), papers, local knowledge base; run in parallel
Reader       - extracts evidence sentences with their source
Judge        - verdict + confidence; asks for more evidence if unsure
Writer       - final report with citations
Baseline     - ONE single agent with all the same tools (for comparison)


DATA
----
FEVER       - English claims labelled SUPPORTS / REFUTES / NOT ENOUGH INFO (main benchmark)
HotpotQA    - multi-step questions with answers (research mode)
SciFact     - scientific claims with evidence
AraFacts    - Arabic fact-checks (verify availability)
Wikipedia API (English + Arabic), arXiv / OpenAlex APIs


AI CONCEPTS (star concepts of this project)
-------------------------------------------
- LLM layer: Google Vertex AI (Gemini Flash / Pro), plus local Ollama for the LoRA model
                                                               (agentcore/)
- Structured output with Pydantic                              (agentcore/)
- Tracing: tokens, cost, latency per call                      (agentcore/)
- RAG: Vertex AI multilingual embeddings + BM25 keyword search, fused, reranked, with citations
- Parallel agents (searchers)
- Verifier loop (judge asks for more evidence)
- Hallucination control: every citation must point to a real sentence
- Evals: accuracy on FEVER, single agent vs team
- LoRA: fine-tune a small model as the judge (claim + evidence -> verdict)

HOW IT IS SCORED
----------------
- Verdict accuracy (vs FEVER labels), per class
- Citation accuracy: % of citations that really support the verdict
- Cost and time per claim
- Same numbers for: single agent (Gemini), team (Gemini), team + LoRA judge (local)
